## 当前执行流程

启动 → 判断是否 --thinking → ask_model → with_retry → 按 MINI_BACKEND 选择 GPT 路径：
- codex：Responses 风格 payload，reasoning.effort=low/high，现有登录和 SSE 完整响应处理。
- openai：官方 Chat Completions；GPT-5.5 使用 reasoning_effort=low/high 和 max_completion_tokens。

两条路径输出统一格式，run_agent 收集工具请求 → 执行本地工具 → 结果回传 GPT → 回答或继续。服务清理不改变工具名、参数、规则加载或会话行为。
